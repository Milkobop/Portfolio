Hellbound Escape

About

Hellbound Escape is a 2D dungeon crawler prototype inspired by titles like The Binding of Isaac. Developed using object‑oriented programming techniques in Unity, the game features self‑made assets and dynamic AI. Enemies patrol randomly when distant, but chase the player when in range. Items like a speed‑boosting screw, a healing potion, and boots that permanently increase speed are programmed to affect gameplay uniquely.

Project Info

  • Role: Gameplay Programmer
  • Team Size: 1
  • 4 Weeks
  • OOP Programming

Introduction

In Hellbound Escape, the prototype was built to test the viability of a dungeon crawler using OOP principles. The enemy AI and item mechanics were iteratively refined through playtesting. For more technical details on the implementation, please refer to my GitHub and itch.io pages.

What I Learned

I learned a great deal about structuring code for dynamic enemy behavior, balancing gameplay through item effects, and ensuring responsive controls in Unity. The project helped me understand the benefits and challenges of OOP in game design.
