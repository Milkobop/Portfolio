Dreamscape Island

About

Dreamscape Island is an interactive shader programming showcase built in Unreal Engine. A collection of custom HLSL shaders — from stylised water and atmospheric fog to post-process effects — all brought together in a single explorable environment.

Project Info

  • Role: Shader Programmer
  • Team Size: 1
  • Duration: Shader Showcase
  • Engine: Unreal Engine
  • Language: HLSL

Introduction

Dreamscape Island was created as a dedicated shader programming project to push my technical understanding of real-time graphics. Rather than a traditional game, the project serves as an interactive portfolio of visual techniques — each area of the island showcasing a different shader effect, from stylised toon rendering to dynamic environment effects.

What I Learned

Writing custom HLSL shaders within Unreal Engine's material system. Implementing techniques such as stylised water simulation, rim lighting, vertex displacement, and post-process effects. Gained a deeper understanding of how the GPU pipeline works and how to optimise shader complexity for real-time performance. This project significantly strengthened my graphics programming foundation.
